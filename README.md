# depth-tools — Карта глубины из фото (Depth Anything V2 + UI)

Локальные инструменты для генерации карт глубины из фото и совмещений, без облака.

## Компоненты

- `depth_from_photo.py` — простой конвейер: фото -> карта глубины, оверлей, DoF, сравнение "цвет + глубина". Настройки вверху файла.
- `depth_ui.py` — графический интерфейс (tkinter): выбор фото через системный диалог (zenity на Linux, нативный на Windows), выбор модели (Small/Base/Large/MiDaS/ZoeDepth/Indoor/Outdoor-варианты), слайдеры, предпросмотр (глубина / оверлей / DoF / цветная карта / фото), крупный просмотр с зумом, точка фокуса для DoF по клику, глубокие форматы (16-бит PNG, float TIFF, EXR).
- `depth_tune.py` — интерактивный подбор настроек через вопросы.
- `depth_gen.py` — процедурный рендер сцены (сферы) с точной глубиной, без нейросети.

## Установка за один клик

### Windows

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Двойной клик по **`depth_ui.bat`** — он сам:
   - установит Python 3, если его нет;
   - создаст виртуальное окружение и поставит зависимости;
   - скачает модель (~99 МБ);
   - создаст ярлык «Карта глубины» на рабочем столе;
   - запустит приложение.

> Если что-то пошло не так — рядом с `depth_ui.bat` появится файл **`depth_ui.log`**
> с пошаговым журналом установки и текстом ошибки. Пришлите его содержимое.

### Linux

```bash
git clone https://github.com/Dlicak/depth-tools
cd depth-tools
chmod +x install.sh
./install.sh
```

`install.sh` сам поставит python3-venv (через sudo), окружение, зависимости, скачает модель и запустит приложение.

## Модель

Комбобокс **«Модель»**: Small (~99 МБ, быстро) / Base (~390 МБ, детальнее) / Large (~1.3 ГБ, максимум деталей), а также MiDaS, ZoeDepth и метрические Indoor/Outdoor-варианты Base/Large. Нужная модель скачивается автоматически при первом запуске. Каталог данных: `~/Z-depth` / `%USERPROFILE%\Z-depth`.

Все пути на обеих ОС портативные (см. «Пути» ниже).

## Результаты

Файлы сохраняются в каталоге данных (`~/Z-depth` / `%USERPROFILE%\Z-depth`): `photo_depth.png`, `photo_depth_overlay.png`, `photo_dof.png`, `photo_color_plus_depth.png`, `photo_colormap.png`, `photo_depth_16.png`, `photo_dof_16.png`, `photo_colormap_16.png` (16-бит), `photo_depth_32.tif` и `photo_dof_32.tif` (32-бит float TIFF), `photo_depth.exr` (half-float EXR) — глубокие форматы включаются соответствующими флажками.

При включённой галочке **«Гибрид»** (вторая цепочка рендера) промежуточные рендеры тоже сохраняются отдельно: `photo_colormap_1.png/.exr` и `photo_depth_1.png`, а результат второго рендера — `photo_colormap_2.png/.exr` и `photo_depth_2.png`; финал — смесь цветов первого и второго рендера 50/50.

## Предупреждение про ОЗУ

**«Множитель»** — множитель размера входа модели. Без «Эконом ОЗУ» диапазон 1–5, и **5x может потребовать более 32 ГБ ОЗУ**. Начинайте с 1–2x. С «Эконом ОЗУ» диапазон 1–10 — вход сжимается к 200 px × множитель, расход памяти небольшой. Если ОЗУ всё же закончилось — обработка автоматически остановится с сообщением.

## Сжать оригинал до

Память модели растёт как квадрат разрешения входа, поэтому большие фото даже при 2x легко «съедают» десятки ГБ. Опция **«Сжать оригинал до»** уменьшает исходное фото в 1–4 раза **до** модели: `1x` — оригинал, `2x` — половина стороны, `3x` — треть, `4x` — четверть. Дальше всё считается уже с уменьшенного: разрешение входа, размер выхода, потребление ОЗУ.

| Сжать оригинал до | Размер фото | Вход при множителе 2 |
|---|---|---|
| 1x | 1920×2560 | 3840×5120 (только CPU, много ОЗУ) |
| 2x | 960×1280 | 1920×2560 |
| 3x | 640×853 | 1280×1706 |
| 4x | 480×640 | 960×1280 |

«Размер выхода» считается от сжатого размера: например, сжатие 2x + выход 1x дадут карту 960×1280.

## EXR-файлы

- `photo_depth.exr` — относительная глубина 0–1 во всех каналах
- `photo_colormap.exr` (флажок «EXR цветная») — RGB = цветная карта палитры, **альфа-канал = глубина 0–1**. В Blender геонодах берите глубину из выхода Alpha текстуры, цвет точек — из Color

## Пути (портативно, без хардкода)

Все пути определяются автоматически и настраиваются через переменные окружения:

| Переменная | Linux | Windows | Назначение |
|---|---|---|---|
| `DEPTH_TOOLS_HOME` | `~/Z-depth` | `%USERPROFILE%\Z-depth` | Каталог данных (настройки, результаты) |
| `DEPTH_TOOLS_MODELS` | `$DEPTH_TOOLS_HOME` | `%DEPTH_TOOLS_HOME%` | Где искать ONNX-модели |
| `DEPTH_TOOLS_SRC` | свежий файл в `~/Downloads` | свежий файл в `%USERPROFILE%\Downloads` | Исходное фото по умолчанию |

Каталог данных создаётся автоматически. Модель ищется в каталоге моделей и рядом со скриптом; если её нет — понятная ошибка вместо падения.
